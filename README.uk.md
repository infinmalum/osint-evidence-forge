# OSINT Evidence Forge (Українська)

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [Русский](README.ru.md)

**Навичка епістемічної гігієни для ШІ-агентів, що займаються відкритими розслідуваннями.**

OSINT Evidence Forge — це навичка для [Hermes Agent](https://hermes-agent.nousresearch.com), яку також можна використовувати як універсальний agent skill. Вона вчить ШІ-агента відновлювати розслідувальні зачіпки з різнорідних доказів: листування, зображень, відео, метаданих, таймлайнів, фінансових даних, транспортних патернів та географії.

Її головна цінність — **не** прийоми вгадування локацій, а дисциплінарний конвеєр, який утримує агента в чесності, коли докази зашумлені, фрагментарні, суперечливі та забруднені ретроспекцією:

```text
дослівні докази → провенанс → конкуруючі гіпотези
→ зважування за розрізнювальною силою → контрфактичні перевірки
→ поширення виправлень → обмежені висновки
```

## Що вона enforcing'ує

Навичка побудована навколо десяти **жорстких інваріантів**, зокрема:

1. **Часові межі T0/T1/H** — розділяйте, що було відомо тоді, що дізналися пізніше і що відомо лише post hoc; ретроспектива ніколи не виправдовє минулі рішення заднім числом.
2. **Дослівний розбір до висновку** — кваліфікатори, прийменники, займенники та апроксиматори розбираються до переказу; змінений розбір анулює всі залежні висновки.
3. **Реєстр конкуруючих гіпотез** — висновки це переглядовані кандидати з підтримкою, суперечностями, припущеннями та умовами відмови; новий доказ перевіряється проти *кожного* кандидата, ніколи не підганяється під поточного фаворита.
4. **Сумісність ≠ підтримка** — «немає конфлікту» дає нуль і ніколи не підвищує кандидата.
5. **Тривісна оцінка доказів** — надійність × розрізнювальна сила × незалежність; істинний, але нерозрізнювальний факт нічого не локалізує.
6. **Воронка, а не ланцюг** — структурні обмеження (транспорт, напрямки, час-дистанція, зв'язки) перетинаються до візуального зіставлення; висновки зобов'язані витримувати ablation-тест.
7. **Смуги, а не точки** — фізичні вимірювання та словесні оцінки часу поширюються як смуги обмежень, без хибної точності.
8. **Предиктивна верифікація геолокації** — перш ніж оголосити локацію, передбачте, що ще має бути видно з передбачуваної позиції, і підтвердьте кожен пункт.
9. **Негативні докази вимагають покриття** — «я шукав і не знайшов» вважається доказом лише після запису охоплення пошуку та виявності.
10. **Межі безпеки** — жодного переслідування, деанонімізування або невиправданих точних приватних локацій; біометрична ідентифікація залишається зовнішнім авторизованим людським кроком; надзвичайні ситуації щодо благополуччя передаються реальним рятувальним службам.

## Встановлення

### Hermes Agent

```bash
hermes skills install <URL-репозиторія-або-шлях>
```

Або клонуйте прямо в `~/.hermes/skills/research/osint-evidence-forge/`.

### Інші агенти (Claude Code, Cursor та рантайми, сумісні з SKILL.md)

Навичка використовує стандартну розкладку `SKILL.md` + `references/` і не потребує виконання коду. Вкажіть репозиторій у каталозі навичок вашого рантайму або скопіюйте `SKILL.md` та `references/` до його теки навичок.

## Джерела методології

Процедури дистильовані з реальних розслідувань та їхніх post hoc-розборів, включно з кейс-стаді геолокації та верифікації в дусі опублікованих методів [Bellingcat](https://www.bellingcat.com) (прогресивна геолокація, хронолокація, тіньові обмеження, пошукові сітки, відновлення джерел), а також з досвіду цивільного розслідування з пошуку людини в цілях благополуччя. Жодних реальних назв справ, суб'єктів, локацій або даних не включено — усі приклади синтетичні.

## Безпека

Навичка призначена для журналістів, дослідників, фахівців із захисту та законних розслідувачів. Вона явно відмовляється від переслідування, деанонімізування та невиправданого розкриття приватних осіб. Повну модель «повноваження + методи» див. у розділі *Safety and Authorization Boundary* у `SKILL.md`.
